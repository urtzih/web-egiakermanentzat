# Documentación restringida de la asociación

Esta carpeta contiene copias locales de documentos entregados directamente por la familia o la asociación para el Discovery.

## Reglas

- Los binarios están excluidos de Git mediante `.gitignore` porque pueden contener firmas, identificadores personales, datos bancarios o metadatos que no deben publicarse automáticamente.
- `manifest.csv` registra existencia, origen, hash, alcance de la revisión y tratamiento.
- Los datos necesarios para la web se trasladan de forma minimizada a los documentos de Discovery.
- Ningún documento de esta carpeta se moverá a `public/`, al CMS o a una descarga pública sin una decisión específica y revisión de privacidad.
- El certificado bancario sirve para confirmar titularidad y datos de transferencia; los identificadores personales de apoderados no se copiarán a la web.

`CONFIRMADO` Copias recibidas y revisadas el 2026-07-21.

`RIESGO` Esta carpeta no sustituye un archivo documental seguro de la asociación. Las copias locales ignoradas por Git pueden perderse y deberán conservarse también en el archivo oficial de la entidad.
