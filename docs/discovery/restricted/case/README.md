- `SRC-056` ayuda a comprobar el enfoque y la terminología en euskera.
- `SRC-057` amplía el análisis familiar, pero no convierte sus conclusiones en hechos acreditados.

- Los documentos oficiales originales prevalecen para resoluciones, autopsia, atestados y actuaciones institucionales.
- Los fotogramas de videovigilancia, las personas identificables y las hipótesis no acreditadas permanecen restringidos.
