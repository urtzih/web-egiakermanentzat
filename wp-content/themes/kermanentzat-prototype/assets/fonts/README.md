# Tipografías del tema

- **Anton**, copyright de sus autores, se distribuye bajo SIL Open Font License 1.1.
- **Public Sans**, desarrollada inicialmente para el U.S. Web Design System, se distribuye bajo SIL Open Font License 1.1.
